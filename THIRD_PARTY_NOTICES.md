# Third-party notices

The local display font is a subset derived from DejaVu Sans Bold. Its license is included at `public/fonts/LICENSE.txt`. Keep that file with the font.

Runtime dependencies are installed from the npm versions pinned in `package-lock.json`. Their package distributions include their respective license files. The Next.js, React and Tailwind packages use their upstream open-source licenses; Lucide icons are supplied through `lucide-react` under its upstream license.

Farm illustrations and existing image assets are included from the Fieldora project. The interface labels its sample farmer imagery and data as illustrative. The external MANA website was used as a design reference; its brand assets are not bundled in this Vercel project.

The optional original Sites source ZIP preserves the original source and its bundled notices.
